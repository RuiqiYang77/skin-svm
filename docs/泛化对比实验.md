# 数据增强泛化能力对比实验

## 实验目的

对比使用 600 张（原数据集）和 1200 张（新增旋转 ±15°、HSV 抖动 + 模糊、Cutout 遮挡）训练的 SVM 模型在独立外部测试集上的泛化能力。

## 测试集

独立外部测试集（`G:/skin/test`），150 张，三类各 50 张，无增强版本。

## 结果

| 指标 | 600 张训练 | 1200 张训练 | 变化 |
|------|:---------:|:----------:|:----:|
| **Macro F1** | 0.672 | **0.730** | **+0.058** |
| MEL F1 | 0.558 | **0.635** | +0.077 |
| NV F1 | 0.520 | **0.626** | +0.106 |
| VASC F1 | **0.938** | 0.928 | -0.010 |
| MEL Recall | 0.580 | **0.660** | +0.080 |
| NV Recall | 0.520 | **0.620** | +0.100 |
| VASC Recall | **0.900** | **0.900** | 持平 |

## 结论

1. **数据增强提升了泛化能力。** 1200 张训练在外部测试集上 Macro F1 比 600 张高 0.058，MEL 和 NV 均有明显提升（+0.077 / +0.106）。

2. **VASC 不受影响。** VASC 在颜色空间上与 MEL/NV 几乎正交，少量增强不会改变其区分度。

3. **内部划分测试无提升。** 用 1200 张本身划分训练集/测试集，Macro F1（0.853）反而略低于 600 张（0.874），因为内部测试集包含了旋转/blur/cutout 图像，增加了评估难度。增强的好处不在自身划分上体现。

4. **泛化能力确实提升了。** 在干净的外部测试集上，1200 张显著优于 600 张（0.730 vs 0.672），说明数据增强提升了模型对真实数据的泛化能力。这一效果只有用外部测试集才能体现。

4. **绝对数值偏低。** 0.730 的 Macro F1 低于内部测试的 0.874，说明外部测试集与训练集分布差异较大，特征在不同数据域间的迁移性有待提高。
